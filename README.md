# AlspencerOmondi.com

Personal website for Alspencer Omondi.

## Structure

- `index.html` — static single-page site
- `styles.css` — responsive visual system and cheetah animation
- `script.js` — lightweight interaction and reveal effects
- `CNAME` — GitHub Pages custom domain

## Deploy

This site is intentionally dependency-free. Enable GitHub Pages for the repo and
serve from the root of the default branch.
